# 0030 스튜디오 단축키 기본값과 설정 재정의

Status: accepted
Source: changes/048-shortcut-settings/spec.md

## 맥락
결정 0016은 자르기의 기본 키를 재생 헤드 S와 포인터 C로 정한다. 사용자는 스튜디오의 편집 동작을 자신의 키 조합에 배정해야 한다.

## 결정
- 결정 0016의 자르기 키 조항을 보완한다. 기본 키는 포인터 자르기 C, 재생 헤드 자르기 S, 재생·일시 정지 Space, 묶기 M, 풀기 Shift+M, 실행 취소 Mod+Z, 다시 실행 Mod+Shift+Z, 삭제 Backspace다. Delete 입력은 Backspace와 같은 조합으로 처리한다.
- 사용자는 설정의 「단축키」에서 여덟 동작의 조합을 재정의한다. 동작마다 물리 키 조합 하나를 엔진 settings.json의 studioShortcuts에 저장한다. 표는 모든 프로젝트와 앱 재실행에 적용한다.
- Mod는 macOS의 ⌘와 Windows의 Ctrl이다. 배정할 수 있는 수정키는 Mod·Alt·Shift다. macOS의 Ctrl 조합은 배정하지 않는다.
- 기존 보조 조합 ⌘M·⌃M·⌃Z·⌃⇧Z·⌘⌫·⇧⌫를 제거한다. 플랫폼별 글 편집·시스템·앱 메뉴 예약 조합과 다른 동작의 조합은 저장하지 않는다.
- 글 입력과 물리 Space의 포커스 보호는 변경 051의 판정을 유지한다. 잘못된 저장 표는 기본값으로 복원한다.
- 스튜디오의 단축키 표시는 툴바 「단축키」 팝오버에 둔다. 실행 취소·다시 실행 버튼의 접근 이름에는 현재 키를 넣고 title은 제거한다. 단축키 툴팁·도움말·상시 목록은 두지 않는다.

## 결과
설정·표시·실행은 같은 단축키 표를 사용한다. 새 키를 저장하면 옛 키는 해당 동작을 실행하지 않는다. 충돌 검사와 플랫폼별 예약 검사는 UI와 엔진이 공유한다. 결정 0016의 나머지 편집 모델과 실행 조건은 유지한다.
