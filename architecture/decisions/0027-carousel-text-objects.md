# 0027 캐러셀 글: 배경은 글자 없이 만들고 글은 객체로 얹는다

Status: accepted
Source: changes/044-carousel-workflow/spec.md
Supersedes: 0019

## 맥락
0019 는 이미지를 글자 없는 배경으로 만들고 제목·본문을 앱이 Pretendard 로 얹되 위치 셋(위·가운데·아래)만 두었다. 사용자는 글의 자유 배치와 효과를 원한다. uUu 는 글 객체마다 좌표·폰트·크기·색·정렬을 둔다.

## 결정
- 이미지는 사용자 codex 로그인(ChatGPT 구독)의 내장 image_gen 도구로 글자 없는 배경을 만든다. 설정의 모델·퀄리티·비율(4:5·1:1·9:16·16:9)·동시 실행 수와 요청 크기·자르기 규칙은 0019 와 같다.
- 장의 글은 객체 2~5개(제목·본문 고정, 추가 3개)다. 객체마다 글, 위치·폭(장 크기 비율), 폰트(자막과 같은 Pretendard·G마켓 산스·티몬체), 굵기 400·700, 크기 12~200px(1080 기준), 색, 정렬, 효과(없음·그림자·반투명 바·외곽선), 투명도를 가진다. 미리보기에서 끌어 옮기고 폭을 바꾼다.
- 로고는 설정의 워터마크 이미지를 켜서 위치·폭·투명도를 정한다. 배경은 밝기 0.2~2.0, 아래쪽 음영 0~0.9 를 둔다.
- 미리보기와 받는 PNG 는 같은 Remotion 컴포넌트로 합성한다. 넘침 판정은 화면에서 하고 받기 전에 확인한다.
- 기획(장마다 제목·본문·이미지 지시문, 게시 캡션)과 주제 다듬기는 대본과 같은 codex 모델·effort 설정을 쓴다. 화풍은 사용자가 요청 때 한 줄로 주거나 AI 가 정한다.

## 결과
글을 고쳐도 이미지를 다시 만들지 않는다. 저장된 장의 `title`·`body`·`textPlacement` 는 읽을 때 같은 모양의 객체 둘로 바뀐다. 외곽선 효과는 웹뷰와 렌더의 글자 외곽선 구현 차이를 plan 에서 확인한다.
