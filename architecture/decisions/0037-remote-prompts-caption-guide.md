# 0037 기본 프롬프트 원격 갱신과 전역 자막 지침

Status: accepted
Source: changes/062-global-caption-guide/plan.md
Supersedes: 0035

## 맥락
0035 의 원격 기본 프롬프트는 사용자가 고치지 않은 프롬프트에만 적용된다. 대본·말투·성격을 고친 사용자에게는 원격 기본값이 바뀌어도 새 내용이 들어가지 않는다. 모든 사용자에게 공통으로 적용할 자막 표기·가독성 규칙을 원격으로 바꿀 방법이 없었다.

## 결정
- 기본 프롬프트 다섯 개(대본, 말투, 성격, 캐러셀 「주제로」·「영상으로」)와 전역 자막 지침(`captionGuide`)을 GitHub `smpbrighton/u3` 의 고정 태그 `prompts` prerelease 자산 `prompts-schema-<N>.json` 에 둔다. 앱은 자기 `PROMPT_SCHEMA` 번호의 파일만 읽는다. 이 자산은 버전 Release 가 아니므로 교체해서 갱신한다.
- 정본은 앱 코드의 상수와 `PROMPT_REVISION` 이다. 앱은 원격 캐시와 앱에 든 기본값 가운데 revision 이 큰 쪽을 쓴다.
- 설치본 엔진은 시작 때와 6시간마다 받아 검증하고, revision 이 클 때만 캐시를 바꾼다. 개발 실행은 받지 않고 캐시도 쓰지 않는다.
- 설정 키가 없거나 비어 있는 프롬프트는 현재 기본값을 따른다. 말투·성격도 같다. 고친 프롬프트는 바꾸지 않고, 그 프롬프트의 기본값이 바뀌면 표시만 한다.
- 전역 자막 지침은 사용자 설정이 아니다. 설정 화면과 저장 키가 없다. 영상 대본 생성 프롬프트에 사용자 설정과 관계없이 항상 합치며, 위치는 말투·성격 뒤, 형식 규칙 앞이다. 빈 값이면 넣지 않는다. 캐러셀 기획에는 넣지 않는다.
- `captionGuide` 가 없는 파일은 빈 지침으로 읽는다. schema 번호는 바꾸지 않는다.
- 설정 화면의 프롬프트 입력은 입력 1초 뒤, 입력란을 벗어날 때, 화면을 떠날 때 저장한다.
- 서명은 하지 않는다. HTTPS 와 내용 검증만 한다.
- `scripts/publish-prompts.sh` 가 깨끗한 main 의 기본값을 올린다. 앱 릴리스와 분리한다.

## 결과
프롬프트·말투·성격·전역 지침만 바꿀 때 앱 릴리스가 필요 없다. 전역 지침은 프롬프트를 고친 사용자에게도 적용된다. 대본 검사는 지침이 허용하는 말줄임표와 초성을 막지 않는다. 원격 갱신은 릴리스 노트 없이 생성 결과를 바꾼다. 원본 본문은 앱 코드의 상수이고 git 이력에 남는다.
