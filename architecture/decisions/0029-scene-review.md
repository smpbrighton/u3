# 0029 장면 검토: 자동 생성 클립은 장면 번호를 갖고 스튜디오 「장면」 탭에서 짤·효과음을 바꾼다

Status: accepted
Source: changes/045-caption-scene-review/spec.md

## 맥락
U3 의 핵심은 자동으로 짤과 효과음을 넣는 것인데, 자동 생성 결과는 타임라인 편집기로 바로 떨어져 장면마다 무엇이 왜 들어갔는지 한 곳에서 보고 바꿀 수 없었다.

## 결정
- 대본에서 만든 자막·짤(겹친 영상)·효과음 클립은 `sceneIndex` 를 가진다. 저장된 프로젝트는 클립 id `scene-N-*` 로 읽을 때 채운다. 손으로 넣은 클립은 갖지 않는다. 나누기로 생긴 뒤 조각은 `sceneIndex` 를 잃는다.
- 스튜디오 왼쪽 패널 「장면」 탭은 `script.json` 의 장면마다 자막·짤(앞·뒤 최대 둘, 이유)·효과음을 한 줄로 보인다. 짤은 자동 생성과 같은 순위(Jev, 없으면 검색)의 후보 5개로 바꾸거나 빼거나 넣고, 프로젝트가 이미 쓰는 짤은 후보에서 뺀다(0013). 효과음은 같은 분류(「전체」 토글)에서 바꾸거나 끄거나 넣는다. 바꾼 짤은 길이 min(짤 길이, 2초, 장면 길이)로 앞 짤은 장면 시작, 뒤 짤은 장면 끝에 맞추고(0016) 화면 위치·크기는 유지한다. 넣기는 뒤 짤로 겹치지 않는 가장 아래 트랙에 넣는다(0016). 효과음은 시작을 유지하고 길이 min(1.5초, 파일 길이)다.
- 모든 바꾸기는 타임라인 변경 한 번이고 실행 취소 한 번으로 돌아온다.
- 2 대본 완료에서 스튜디오로 들어갈 때는 「장면」 탭이 열려 있다. 그 밖의 진입은 마지막 탭을 기억한다.

## 결과
자동 생성 결과 검토가 주 동선이 된다. 장면 검토는 프로젝트 폴더의 `script.json` 에 의존하므로 대본 없이 만든 프로젝트에는 「장면」 탭이 비어 있다. 앞·뒤 짤 구분은 클립 id 로 한다.
