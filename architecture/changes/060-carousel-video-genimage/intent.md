## 문제
「영상으로」 캐러셀은 영상 1 의 원본 장면을 그대로 배경으로 쓴다(결정 0026). 사용자 표현: 「캐러셀 생성하기 누르면 영상속에 들고있는 상품장면을 기준으로 gpt 이미지가 생성되어야하는거 아니냐는거지 지금은 그냥 영상속 장면 하나만 나오잖아」. 원본 장면은 손떨림·조명·구도가 촬영 그대로라, 사용자가 기대하는 캐러셀 배경 품질에 못 미친다. 영상 캐러셀을 만드는 모든 사용자가 겪는다.

## 기대 결과
- 「영상으로」 캐러셀에서 이미지 만들기를 누르면, 장마다 고른 영상 장면을 참고 이미지로 GPT 이미지(codex 내장 image_gen)가 만들어져 배경이 된다.
- 생성된 배경의 상품은 참고 장면의 상품과 같은 상품으로 보인다(종류·색·모양·패키지 형태).
- 장면은 지금처럼 장마다 시각으로 고르고 바꿀 수 있다. 장면을 바꾸면 그 장면을 참고로 다시 만든다.
- 범위 밖: 상품 라벨 글자의 정확한 재현, 여러 장면을 합친 합성, 인물 얼굴 보존, 「주제로」 캐러셀의 동작 변경.

## 영향 범위
- 사용자: 「영상으로」 캐러셀을 만드는 사용자. 장마다 이미지 생성 시간(장당 수십 초)과 ChatGPT 사용량이 늘어난다.
- 시스템: 캐러셀 생성 라우트의 영상 파생 분기, 영상 캐러셀 기획 프롬프트(원격 기본 프롬프트 포함, 0035), 캐러셀 편집 화면의 배경 절, 강조(Jev Box·AI 윤곽).
- 외부 연동: codex CLI image_gen(참고 이미지 첨부), Jev Box.

## 제약
- 이미지 생성은 codex 내장 image_gen 만 쓴다(0015·0027). 설정의 모델·퀄리티·비율·동시 수를 따른다.
- 배경에 글자를 만들지 않는 규칙(0027)과 상품 패키지의 글자가 충돌한다.
- 결정 0026 의 「영상 파생은 영상 1 원본 프레임을 배경으로 쓴다」를 대체한다.
- 기획 검토 없이 이미지를 만들지 않는 흐름(0026)은 유지한다.

## 열린 질문
1. 원본 장면 배경을 장마다 고를 수 있게 남길지(「AI 이미지 / 원본 장면」 전환).
2. 새 영상 캐러셀의 기본값을 AI 이미지로 할지.
3. 상품 라벨 글자를 어떻게 다룰지(살리라고 지시 · 지우라고 지시 · 지시 없음).
4. 강조(Jev Box 상자·AI 윤곽)를 생성 이미지에도 적용할지.
5. 이미지 지시문을 기획 단계에서 장마다 만들어 검토 화면에서 고칠 수 있게 할지.
6. 영상 캐러셀 기획 프롬프트의 「실제 프레임 이미지는 제공되지 않았다」·「새 배경 이미지 제작 지시문을 추가하지 않는다」 규칙을 어떻게 바꿀지.
