# Plan: script-voice-prompts (lite)
Track: lite. 일괄 승인 계획(030·032·033·034)의 한 부분이다. 공통 절은 아래 「일괄 계획 공통」에 있다.

### 결정
- 사용자 지시 원문: 「대본 프롬프트가 기존 uuu에서 스티븐이 작업한 대본이 아니라서 대본이 어색해 휴머나이저 아임낫에이아이 등의 스킬을 사용해서 대본을 잘 만들어뒀던게 있는데 그걸 그대로 사용하게끔 대본 고도화 기능과 대본 뿐 아니라 화자의 말투 성격 등을 제어할 수 있는 또다른 프롬프트도 몇가지 더 설정에 프롬프트 하단에 추가해줘.」「(앱이 항상 덧붙이는 규칙 목록) 이건 삭제하고.」
- uUu v12(`/Volumes/X31/workspace/smp_workspace/uUu/prompts/script.default.md`, 읽기 전용)에서 언어집·프레임 흐름·말투·과장·시제와 말끝·동작과 원인·결과·문장부호·AI 티 줄이기(im-not-ai MIT 출처 줄 포함)를 옮긴다. 「상품」은 「영상 속 대상」으로, 「나레이션」은 「자막」으로 바꾼다. 상품·채널 변수, 공개 단어, visual, upload, emphasis, TTS 억양 설명은 뺀다.
- humanizer(blader/humanizer) 원문은 uUu 에도 커밋되어 있지 않다. 옮기지 않는다. 「AI 티 줄이기」 절이 그 역할을 한다.
- 자막 검수: uUu `script-review.default.md` 를 U3 형식에 맞게 옮긴 두 번째 codex 호출. 출력은 같은 `CodexScript` 형식이고, `inputIndex`·`startSec`·`endSec`·`reaction`·`memeBefore`·`memeAfter`·`sfxCategory` 가 바뀌면 검수 결과를 버리고 초안을 쓴다. 실패하면 초안과 경고.
- 설정 「대본 프롬프트」 카드 아래에 「화자」「말투」「성격」「자막 검수」 프롬프트 칸을 둔다. 각 4000자, 빈 값이면 기본값(화자·말투·성격 기본은 빈 값 = 언어집에서 AI 가 고름). 「앱이 항상 덧붙이는 규칙」 목록은 화면에서 지운다.
- 사용자가 이미 고친 대본 프롬프트(`settings.scriptPrompt`)는 그대로 둔다. 고치지 않은 사용자만 새 기본값을 받는다.

### 진행 방식
- 조정자는 코드를 쓰지 않는다. 단위마다 `orca worktree create … --agent codex --model gpt-6-luna --effort high` 로 워커를 띄우고, 재검토 → 워크트리에서 `pnpm verify` → main ff 병합 → 정리를 한다. 같은 단위에서 수정 요청이 3회를 넘으면 멈춘다.
- 동시 워커는 최대 3개다. 워커는 범위 밖 파일을 고치지 않고, 테스트를 고쳐서 통과시키지 않는다. 버그 수정은 실패 테스트를 먼저 커밋한다. CSS·DOM 결함은 테스트 없이 고치고 커밋 본문에 이유를 적는다.
- 각 변경의 계획 커밋 브랜치(030·032·033·034)는 단위 브랜치가 main 에 병합될 때 함께 들어가도록, 첫 단위 워커를 그 변경 브랜치 위에서 시작한다(030 은 W32 병합 뒤 main 에 rebase).
- 끌기 동작은 사용자가 검증한다. W37 병합·설치 뒤 조정자가 확인할 동작 목록과 빌드 위치를 요청으로 낸다.
