## 확인 기록
- 대비 결함(사용자 댓글: 「저장」「대본 만들기」「삭제」 글자가 안 보임): 공통 초기화 규칙이 버튼 글자색을 덮어쓴 원인이다. 초기화 규칙을 `:where()` 로 낮추고 비활성 버튼을 회색 바탕으로 바꿨다. 구현에서도 같은 함정을 피한다(Tailwind preflight 의 `button { color: inherit }` 가 같은 규칙이다).
- 실제 데이터: 프로젝트 「새 영상」의 자막·짤·효과음, 캐러셀 두 개, 앱 라이브러리의 효과음·알림음 이름, `src/core/schema.ts` 의 워터마크·타이틀 바 기본값을 썼다. 알 수 없는 값(대본 안내 문구, 캐러셀 후보, 실패 이유)은 `[…]` 자리 표시로 남겼다.
