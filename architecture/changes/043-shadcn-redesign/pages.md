# 페이지별 기능 명세서: shadcn-redesign

spec 요구사항 11 의 산출물이다. 지금 코드(`src/ui/`)의 기능을 모두 옮겼다. 「바뀜」 표시는 동선을 바꾸는 곳이고 이유를 한 줄로 단다. 「없앰」은 화면 글 규칙(요구사항 12)으로 지우는 글이다. 이 문서에 없는 기능은 디자인과 구현에 넣지 않는다.

사용자 게이트 1(확정): "6번까지 다 넣고 디자인 아티팩트 만들어" — 「바뀜」 항목을 모두 넣는다.

표기: 동작은 「컨트롤 — 결과」로 쓴다. 상태는 빈 상태·진행·오류·완료 순이다.

## 0. 화면 글 규칙 적용 기준
- 지운다: 입력 아래·위 설명문, 도움말 문장, 「예: …」 placeholder, 대화상자의 설명문(되돌릴 수 없는 결과는 예외로 한 줄 남긴다).
- 남긴다: 짧은 명사 라벨, 값(50%, 3.0초), 상태(준비됨, 생성 중), 오류 한 줄, 아이콘 버튼의 툴팁 이름.
- 같은 뜻 반복 금지: 카드 제목과 토글 라벨이 같으면 토글 라벨을 지운다.

## 1. 공통 셸
**하는 일:** 화면 이동, 엔진 연결, 업데이트 표시, 알림.
**대상:** 화면, 엔진 연결, 업데이트 상태.

**동작**
- 사이드바 「영상」「캐러셀」「설정」 — 화면 이동. 현재 화면을 표시한다. 스튜디오에서는 사이드바를 숨긴다(업데이트 표시가 있으면 보인다).
- 사이드바 머리: U3 로고와 「사이드바 접기」 아이콘 버튼. 접으면 폭 64px 에 아이콘만 남고, 아이콘에 마우스를 올리면 화면 이름 툴팁. 접힘 상태는 다시 열어도 유지(localStorage `u3.sidebarCollapsed`). **추가:** 사용자 지시 "사이드바에 로고 … collapse 되게".
- 업데이트 표시(사이드바 아래) — 받는 중 `n%`, 준비되면 「새 버전 x.y.z」와 「다시 시작」.
- 「다시 시작」 — 진행 중 작업이 있으면 확인 대화상자, 없으면 편집 중 화면을 저장하고 다시 시작.
- 알림(토스트) — 한 번에 하나, 5초. 모든 화면의 성공·실패 알림이 여기로 온다.

**상태**
- 엔진 연결 실패: 상단 경고 한 줄 「엔진에 연결하지 못했어요」와 오류 내용, 「다시 연결」. **바뀜:** 「다시 연결」을 더한다. 이유: 지금은 다른 화면으로 이동해야 경고가 사라지고 다시 시도할 방법이 없다.
- 다시 시작 중: 화면 전체 입력을 막는다.
- 다시 시작 실패: 토스트 「다시 시작하지 못했어요」.

**대화상자**
- 다시 시작 확인: 제목 「작업을 중단하고 다시 시작할까요?」, 한 줄 「진행 중인 작업이 중단돼요」, 「취소」「저장하고 다시 시작」. **없앰:** 작업 종류를 나열한 설명문.

**이동:** 모든 화면의 시작점.

## 2. 영상 목록
**하는 일:** 영상 프로젝트를 만들고 연다.
**대상:** 프로젝트 카드(썸네일, 길이, 이름, 장면 수 또는 미디어 수, 마지막 수정 시각, 「대본 전」 표시).

**동작**
- 「새 영상」 — 「새 영상」 프로젝트를 만들고 1 미디어로 간다.
- 카드 누르기 — 프로젝트를 연다. 타임라인에 영상이 있으면 스튜디오, 미디어만 있으면 2 대본, 없으면 1 미디어.
- 카드 메뉴(…) — 「이름 바꾸기」, 「캐러셀 만들기」(타임라인 영상과 영상 입력이 있을 때만), 「삭제」.

**상태**
- 불러오는 중: 카드 자리 표시(skeleton). **바뀜:** 지금은 불러오는 동안 빈 상태 문구가 보인다. 이유: 영상이 있는데 「없어요」가 잠깐 보이는 오표시.
- 빈 상태: 「아직 영상이 없어요」 + 「새 영상」.
- codex 사용 불가: 상단 경고 한 줄 「codex 로그인이 필요해요」 또는 「codex 설치가 필요해요」 + 「설정 열기」. **없앰:** 「대본을 만들 수 없어요」 설명, 화면 밖 안내 문장.
- 오류: 토스트.

**대화상자**
- 이름 바꾸기: 제목 「이름 바꾸기」, 입력 하나, 「취소」「저장」(빈 이름이면 비활성), Enter 저장. **없앰:** 「새 이름을 입력해 주세요.」
- 삭제 확인: 「‘이름’을 삭제할까요?」, 한 줄 「되돌릴 수 없어요」, 「취소」「삭제」. **없앰:** 지워지는 항목 나열.
- 캐러셀 만들기: 6.4 와 같다.

**이동:** 1 미디어·2 대본·스튜디오(열기), 캐러셀 편집(캐러셀 만들기), 설정(codex 경고).

## 3. 1 미디어
**하는 일:** 프로젝트 이름을 정하고 영상·사진을 1~20개 넣고 순서를 정한다.
**대상:** 프로젝트 이름, 미디어 항목(미리보기, 번호, 파일 이름, 종류).

**동작**
- 뒤로 — 영상 목록.
- 이름 입력 — 포커스를 잃으면 저장. **바뀜:** 지금은 뒤로·단계 이동 때 저장되지 않는다. 이유: 고친 이름이 사라진다.
- 단계 표시 「1 미디어」「2 대본」「3 스튜디오」 — 이동. 미디어가 없으면 2, 타임라인 영상이 없으면 3 이 비활성.
- 넣기 영역 — 누르면 파일 선택, 창 어디든 끌어 놓기 가능. 지원 형식 mp4·mov·m4v·jpg·jpeg·png·heic·webp, 최대 20개. 20개면 비활성. **없앰:** 형식·개수 안내 문장(지원하지 않는 파일을 넣으면 오류 한 줄로 알린다).
- 항목 순서 — 끌어서 바꾸기, 위·아래 아이콘 버튼.
- 항목 빼기 — 즉시 뺀다.
- 「다음: 대본」 — 이름 저장 후 2 대본. 미디어가 없으면 비활성.

**상태**
- 빈 상태: 넣기 영역만 크게 보인다.
- 넣는 중: 넣기 영역에 진행 표시. **바뀜:** 지금은 진행 표시 없이 컨트롤만 막힌다.
- 오류: 「mp4·mov 영상이나 jpg·png·heic 사진만 넣을 수 있어요」, 「20개까지 넣을 수 있어요」 토스트.

**이동:** 영상 목록, 2 대본, 스튜디오.

## 4. 2 대본
**하는 일:** codex 로 장면 대본을 만들고 타임라인을 짠 뒤 스튜디오로 간다.
**대상:** 대본 방식, AI 가 볼 프레임, 간략한 대본 글, 생성 작업.

**동작**
- 뒤로 — 1 미디어. 단계 표시는 3 과 같다.
- 방식 탭 「AI 추천」「직접 쓰기」. **없앰:** 두 방식의 설명문.
- AI 추천: 프레임 묶음(입력별 번호·파일 이름·길이, 프레임마다 시각) 보기만. 개수 `n / 40`.
- 직접 쓰기: 여러 줄 입력 「간략한 대본」. **없앰:** 설명문, 「예: …」 placeholder.
- 「대본 만들기」 — 생성 시작. codex 사용 불가·진행 중·프레임 불러오는 중에는 비활성. 직접 쓰기에서 글이 비면 오류 한 줄.
- 「취소」 — 진행 중 생성 취소.

**상태**
- 프레임 불러오는 중: 자리 표시. 프레임 없음: 「이미지가 없어요」.
- 생성 중: 진행 막대와 단계 문구(「대본 작업 준비 중」「codex 실행 중」「말투 규칙에 맞춰 다시 생성 중」「대본 추천 완료」), 「취소」.
- 완료: 스튜디오로 이동하고 토스트 「대본을 만들었어요」. 안내(받아 적기·대본 말투·짤을 넣지 못한 장면 수)는 스튜디오의 알림 목록에서 다시 볼 수 있게 한다. **바뀜:** 지금은 5초 토스트로만 보이고 사라진다. 이유: 말투 위반 안내를 놓친다.
- 오류: 경고 한 줄과 「다시 시도」.
- codex 사용 불가: 2 와 같은 경고 한 줄 + 「설정 열기」.

**이동:** 1 미디어, 스튜디오.

## 5. 스튜디오
**하는 일:** 타임라인에서 영상·자막·짤·소리를 편집하고 mp4 로 내보낸다.
**배치:** 머리줄 / 왼쪽 라이브러리 / 가운데 미리보기 / 오른쪽 인스펙터 / 아래 툴바와 타임라인.

### 5.1 선택 규칙 **(바뀜)**
- 대상 하나를 고르면 인스펙터는 그 대상의 속성을 맨 위에 보인다. 그 대상이 속한 묶음(자막 레이어, 영상 트랙, 소리 트랙)의 속성은 아래에 접는 묶음으로 둔다.
- 타임라인 클립과 미리보기 객체는 같은 선택을 공유한다. 한쪽에서 고르면 다른 쪽도 표시된다.
- 타임라인 빈 곳을 누르거나 Esc 를 누르면 선택이 풀리고 인스펙터는 「브랜드」로 돌아간다. 이유: 지금은 선택을 풀 방법이 없다.
- Shift+클릭은 모든 트랙에서 선택에 더한다. 이유: 지금은 자막·소리 트랙에서 Shift+클릭하면 선택이 비는 결함이 있다.

### 5.2 머리줄
- 뒤로 — 2 대본. 프로젝트 이름 표시.
- 「캐러셀 만들기」 — 6.4 대화상자.
- 「저장」 — 저장, 토스트 「저장했어요」. 저장하지 않은 변경이 있으면 버튼 옆 점 표시. **바뀜:** 점 표시를 더한다. 이유: 자동 저장이 없는데 저장 필요 여부가 보이지 않는다.
- 「mp4 내보내기」(주요 동작, 주황) — 저장 후 5.9 내보내기.
- 알림 목록(종 아이콘) — 대본 생성 안내를 다시 본다(4 의 바뀜).

### 5.3 라이브러리
탭 「미디어」「짤」「효과음」「음성」.
- 미디어: 「넣기」(파일 선택), 항목(썸네일·이름·종류·길이). 누르기 — 영상 1 끝에 붙인다. 끌기 — 영상 1 클립 위·영상 2 이상 트랙이면 그 시각의 겹친 영상, 영상 끝 뒤면 영상 1 끝에 붙인다. **없앰:** 「영상·사진 파일을 선택해요」「끌어 놓으세요」 설명.
- 짤: 검색(400ms 뒤 Jev 다시 순위), 검색 없으면 24개씩 이어 보기, 마우스를 올리면 재생. 누르기 — 선택한 짤 클립을 바꾸거나, 없으면 재생 헤드에 새 겹친 짤. 끌기 — 새 영상 트랙에 넣는다. 상태: 「Jev 추천」「검색 순서」 표시, 결과 없음 「맞는 짤이 없어요」. **없앰:** 「다른 상황이나 감정으로 찾아 보세요」.
- 효과음: 검색(같은 방식), 항목(제목·분류·길이). 누르기 — 재생 헤드에 효과음 1. 끌기 — 새 효과음 줄.
- 음성: 「녹음」/「멈추기」와 타이머(녹음 중 재생 막음, 원본 소리 음소거), 「파일 불러오기」(m4a·mp3·wav), 「자막으로 음성 만들기」, 음성 클립 목록(누르면 파형). **바뀜:** 「음성 만들기」를 타임라인 트랙 머리에서 이 탭으로 옮긴다. 이유: 트랙 머리 칸이 좁아 이름과 겹친다(0.2.2 결함). 트랙 머리에는 음소거만 둔다. **없앰:** 「재생 헤드 자리부터 녹음해요」「m4a · mp3 · wav 파일을 지원해요」.
- 끌기 중: 따라오는 미리보기, 타임라인 세로 안내선, Esc 취소.

### 5.4 미리보기
- 재생/일시 정지, 시간 `MM:SS.s / MM:SS.s`, 재생 헤드 막대.
- 화면 위 편집: 겹친 영상·짤(이동, 모서리로 비율 유지 크기), 자막(이동), 워터마크(이동·크기). 방향키 1% 이동. 세이프존이 켜져 있으면 그 안으로 붙는다. 끌기 시작하면 재생을 멈춘다.
- **바뀜:** 미리보기에서 자막을 누르면 그 시각의 자막 클립을 고른다(지금은 레이어 투명도만 보인다). 두 번 누르면 그 자리에서 글을 고친다. 이유: 사용자 지시 — 자막별로 바로 고치기.
- **바뀜:** 미리보기에서 워터마크를 누르면 워터마크 속성 전체(위치·폭·투명도)를 보인다(지금은 투명도만).
- 상태: 「미리보기 준비 중」, 「타임라인에 미디어를 넣어 주세요」.

### 5.5 툴바
- 「실행 취소」⌘Z, 「다시 실행」⇧⌘Z(아이콘, 툴팁에 이름과 단축키).
- 「세이프존」「스냅」 토글, 「확대」 1–10(⌘+휠·핀치도 가능).

### 5.6 타임라인
- 트랙(위→아래): 자막 레이어마다 메인·서브, 새 영상 트랙(끌어 놓기 자리), 영상 N…영상 2, 영상 1, 원본 소리(분리 전), 목소리·배경(분리 후), 음성, 효과음 1…N.
- 트랙 머리: 이름, 소리 트랙은 음소거(효과음은 모두 함께, 목소리·배경은 모든 입력 함께).
- 클립: 이름표(자막 글, 파일 이름, 짤 설명, 효과음 제목), 전환 표시, TTS 클립이 자막보다 길면 「!」(툴팁 「다음 음성과 겹쳐요」).
- 동작: 고르기, Shift 더하기, 묶음 클립 함께 고르기, 끌어 옮기기(영상 1 순서·겹친 영상 시각·트랙 사이·새 트랙), 가장자리 끌어 자르기, 나누기(C=포인터 위치, S=재생 헤드, 영상 트랙만), 삭제(Delete, 영상 1 은 하나 이상 남김), 묶기 ⌘M/M, 풀기 ⇧⌘M/⇧M, 재생 헤드(눈금 누르기·끌기), Space 재생.
- 자막 클립 두 번 누르기 — 그 자리에서 글 고치기. **바뀜** (5.4 와 같은 이유).
- TTS 진행: 타임라인 위 한 줄(문구·진행 막대·「취소」).

### 5.7 인스펙터(선택한 대상별)
모든 한 줄 속성은 「라벨 — 컨트롤 — 값」 한 줄이다.
- **선택 없음 → 브랜드**
  - 워터마크: 켜기, 가로 위치·세로 위치·폭·투명도(%). 이미지가 없으면 「설정에서 이미지 선택」 링크 한 줄.
  - 타이틀 바: 켜기, 글/이미지, 글(30자, 「제목 다시 만들기」 — 자막이 없으면 비활성), 높이(px)·글자 크기(px)·투명도(%). 이미지가 없으면 설정 링크 한 줄. **없앰:** 「설정에서 … 선택해 주세요」 문장.
- **자막 클립 → 이 자막 (바뀜)**
  - 맨 위: 메인 글, 서브 글(둘 다 여러 줄 입력). 시작·길이(초).
  - 아래 접는 묶음 「레이어 스타일」: 레이어 이름, 폰트(Pretendard·G마켓 산스·티몬체), 메인 크기 20–100·서브 크기 16–80(값 표시), 글자 색, 글자 투명도(%), 자막바 켜기·색·투명도, 「메인·서브 바꾸기」, 「서브 자막 만들기」(진행 표시·오류 한 줄 **바뀜:** 지금은 진행·오류 표시가 없다), 「레이어 더하기」, 「레이어 지우기」(하나면 비활성).
  - 이유: 사용자 지시. 지금은 자막 클립을 누르면 레이어 스타일만 보이고, 글은 영상 1 클립을 골라야 그 구간의 첫 메인 자막 하나만 고칠 수 있다. 서브 자막은 손으로 고칠 수 없다.
- **자막 레이어(트랙 머리 누르기) → 레이어 스타일** 위 묶음과 같은 내용을 펼친 상태로.
- **영상 1 클립 → 영상 클립**: 투명도, 원본 시작·원본 끝(초, 라벨 보임), 시작 효과·끝 효과, 묶음이면 「묶음 n개」+「묶음 풀기」, 위치·길이 표시. **바뀜:** 자막 글 입력을 여기서 뺀다(자막 클립으로 옮김).
- **영상 1 짤 클립 → 짤**: 투명도, 길이 0.5–4초, 「앞으로」「뒤로」(본 화면 순서), 시작·끝 효과. **없앰:** 「왼쪽에서 다른 짤을 누르면 바꿔요」(짤 탭 누르기로 바꾸는 동작은 그대로).
- **영상 2 이상 클립(영상·사진·짤) → 겹친 영상**: 투명도(여러 개면 모두), 시작 시각, 길이(초), 가로·세로 위치(%), 폭 10–100%, 시작·끝 효과, 묶음 정보, 「삭제」.
- **전환(시작·끝 효과)**: 종류(없음·디졸브·검은 화면 페이드·밀기·와이프·원형 열기·확대 전환), 밀기·와이프는 방향(왼쪽·오른쪽·위·아래), 길이 0.1초–min(2초, 클립 절반). 0.2초보다 짧은 클립은 없음만. **없앰:** 「앞 클립의 끝 효과와 다르면 …」 설명. 대신 두 효과가 다를 때만 「뒤 클립의 시작 효과를 써요」 한 줄 상태를 보인다.
- **원본 소리 → 원본 소리**: 볼륨 0–150%·음소거, 「음성 분리」, 받아 적기 대상(원본 소리·음성), 「자막 만들기」, 진행 줄(문구·진행·「취소」).
- **목소리·배경 → 분리한 소리**: 목소리·배경 볼륨과 음소거, 「분리 되돌리기」, 받아 적기 대상(목소리·음성), 「자막 만들기」, 진행 줄.
- **음성 클립 → 음성**: 트랙 볼륨·음소거, 클립 볼륨 0–150%, 「자막 만들기」, TTS 클립이면 「다시 만들기」와 길이 경고 한 줄. **바뀜:** 이 클립의 받아 적기 진행 줄을 보인다(지금은 원본 소리 쪽에서만 보인다). **없앰:** 「선택한 음성 클립에서 받아 적어요」.
- **효과음 클립 → 효과음**: 트랙 볼륨·음소거, 클립 볼륨, 「효과음 바꾸기」 선택.
- **워터마크(미리보기에서 고름) → 워터마크**: 브랜드의 워터마크 속성과 같다.
- **여러 종류를 함께 고름 → 선택 n개**: 공통 속성(투명도)만, 「삭제」.
- 오류: 인스펙터 위 한 줄.
- 지움: 닿을 수 없는 「자막 속성」 분기(`Inspector.tsx:265`).

## 6. 캐러셀

### 6.3 편집
- 머리줄: 「캐러셀 목록」, 이름, 「모두 받기」(완료한 장이 있을 때), 「전체 취소」(작업 중일 때).

## 7. 설정
**하는 일:** 앱 전체 기본값과 연결 상태를 정한다.
**바뀜(배치):** 세 열 카드 대신 왼쪽 구역 목록 + 오른쪽 내용으로 바꾼다. 구역은 「화면」「브랜드」「대본」「짤」「음성」「이미지 생성」「알림음」「앱 정보」. 이유: 지금은 관련 설정(예: 받아 적기 모델과 대본, TTS 모델과 음성)이 서로 다른 카드에 흩어져 있다.
**바뀜(저장):** 모든 설정은 바뀌면 바로 저장하고, 여러 줄 글은 포커스를 잃으면 저장한다. 실패만 토스트로 알린다. 「저장」 버튼을 없앤다. 이유: 지금은 카드마다 저장 방식이 달라(저장 버튼·바로 저장·놓을 때 저장) 저장됐는지 알 수 없다.

- **화면:** 테마 「다크」「라이트」「시스템 설정 따르기」(기본 다크). 요구사항 9.
- **브랜드**
  - 워터마크: 미리보기, 이미지(「선택」「지우기」), 기본 가로 위치·세로 위치·폭·투명도(%).
  - 타이틀 바: 미리보기, 글/이미지, 기본 글(30자) 또는 이미지(「선택」「지우기」), 높이 40–600px, 배경 색, 배경 투명도(%), 폰트, 글자 크기 12–200px, 글자 색.
- **대본**
  - codex: 상태(확인 중·사용 가능·로그인 필요·설치 필요), 로그인·설치가 필요하면 할 일 한 줄(「터미널에서 codex login」), 설치가 없으면 「실행 파일 지정」, 모델, 추론 강도(모델에 맞게 자동 조정), 「다시 확인」.
  - 받아 적기 모델(whisper 574 MB): 준비됨 / 「받기」 / 진행·「취소」.
  - 대본 프롬프트(여러 줄 20,000자, 글자 수), 말투, 성격(여러 줄 4000자). 각각 「기본값으로」. **없앰:** 「대본을 만들 때마다 …」「비워 두면 …」 설명.
- **짤**
  - Jev: 상태(확인 중·키 없음·연결됨), API 키(저장된 키는 끝 네 자리), 「저장」(키 입력은 예외로 명시 저장, 이유: 비밀값을 칠 때마다 저장하지 않는다), 「지우기」, 서버 경고 한 줄. **없앰:** 「키가 없으면 …」 안내.
  - 짤 검색 모델(bge-m3): 준비됨 / 「받기」 / 진행·「취소」. **없앰:** 상태별 설명문.
- **음성**: 화자(9명, 기본 Sohee), 말투 지시(한 줄), 음성 만들기 모델(약 3.1 GB) 준비됨 / 「받기」 / 진행·「취소」. **없앰:** placeholder 예시.
- **이미지 생성**: 모델(Flare 빠름·Sunburst 고품질), 퀄리티(low·medium·high·auto), 비율, 동시 실행 수 1–10.
- **알림음**: 켜기, 소리 선택과 「미리 듣기」(▶ 아이콘), 시각 0–10초. **없앰:** 카드 제목과 같은 토글 라벨 「자동 알림음 켜기」.
