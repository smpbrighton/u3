## 문제
U3 의 캐러셀 메뉴는 「준비 중」이다. 사용자는 숏폼 영상만 만들 수 있고, 사진 여러 장으로 넘겨 보는 게시물(캐러셀)은 만들 수 없다. uUu 에는 캐러셀 기능이 있었지만 근거 조사·기획안 후보·톤 프리셋·인물 사진·마스크 편집까지 갖춰 무겁다. 사용자는 그중 간단한 흐름만 U3 에 원한다.

## 기대 결과
사용자 말로 쓴 다섯 가지를 한다.
1. 주제 선택. 사용자가 주제를 쓰고, AI 로 그 주제를 고도화할 수 있다.
2. 이미지 병렬 생성. 한 캐러셀에 최대 10장을 동시에 만든다.
3. 이미지별 재생성과 텍스트 수정.
4. 설정에서 이미지 생성 옵션(퀄리티 등 GPT Image 2.5 에 들어갈 옵션)을 고른다.
5. 따로 내보내기 기능은 없다. 생성된 이미지를 한 번에 받는다.

범위 밖: 근거 조사, 기획안 여러 개 비교, 톤 프리셋, 인물·로고 사진 넣기, 마스크로 일부 고치기, 게시글 본문(캡션) 작성, 업로드.

## 영향 범위
- 사용자: 캐러셀 메뉴가 열린다. 설정 화면에 이미지 생성 옵션 카드가 생긴다.
- 시스템: 엔진에 캐러셀 저장·생성 작업이 생긴다. 이미지 생성은 사용자 codex 로그인(ChatGPT 구독)의 내장 image_gen 도구를 쓴다.
- 결정: 0003(범위)은 캐러셀을 제외한다. 이 변경은 0003 을 대체한다. 0009(AI 는 codex·Jev 만)에 codex 이미지 생성 쓰임이 더해진다.

## 제약
- AI 는 codex CLI 와 Jev 만 쓴다(0009). API 키 방식 이미지 생성은 쓰지 않는다.
- 화면은 SEED Design 으로 만든다(W26~W28).
- 실제 사용자 데이터 폴더 밖에 쓰지 않는다. 받기는 사용자가 고른 위치에만 쓴다.
- macOS Apple Silicon 데스크톱 앱(0001).

## 열린 질문
- AI 주제 고도화의 결과는 어떤 모양인가(고친 주제 하나, 또는 후보 여러 개).
- 한 캐러셀의 장 수 범위와 기본값.
- 이미지 비율(1:1, 4:5 등)은 고정인가, 고르는가.
- 텍스트는 이미지에 그려 넣는가, 이미지 위에 따로 얹는가.
- 「병렬」의 동시 실행 수. 구독 한도에 걸리면 어떻게 하는가.
- 「한 번에 받기」의 형식(폴더에 PNG 여러 장, 또는 zip 하나).
- 만든 캐러셀을 목록으로 저장해 다시 여는가.
