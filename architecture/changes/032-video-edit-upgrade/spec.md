## 열린 질문에 대한 답
- 서브 자막을 만드는 주체: 사용자가 직접 쓸 수 있다. 대본 생성 때 codex 가 장면마다 영어 서브 글을 함께 낸다. 받아 적기로 만든 자막은 서브가 비어 있고, 「서브 자막 만들기」를 누르면 codex 가 메인 글을 번역해 채운다. 이유: 0007 은 받아 적기를 한국어로 고정한다. 번역은 0009 의 codex 범위 안이다. 서브 언어는 영어로 고정하고 고르는 설정을 두지 않는다. 용어: 「행」은 메인·서브 두 행을, 「줄」은 한 행 안의 줄바꿈(최대 2줄)을 뜻한다.
- 자막 스타일의 단위: 자막 레이어마다 하나다. 클립마다 다른 스타일은 두지 않는다. 이유: 한 레이어(본 자막, POV 등)는 한 모양으로 보이는 것이 기본이고, 다른 모양이 필요하면 레이어를 더한다.
- 「메인·서브 바꾸기」: 레이어 안 두 줄의 클립을 통째로 맞바꾼다. 위치·크기 규칙(위 56px, 아래 40px)은 그대로다. 이유: 「메인 한글·서브 영어」를 「메인 영어·서브 한글」로 한 번에 바꾼다.
- 서브 줄 클립의 시각: 메인 줄과 따로 자르고 옮긴다. 대본·받아 적기·번역이 만들 때는 메인과 같은 시각으로 만든다. 이유: 번역 문장 길이가 달라 따로 다듬을 일이 생긴다.
- 자동 알림음의 기본 소리: 기본은 켜짐이고, 소리는 라이브러리 notify 의 「띠링- 소리」, 시각은 3.0초다. 사용자는 설정에서 notify 분류의 다른 소리로 바꿀 수 있다. 이유: 「카톡」은 실제 서비스 알림음을 옮긴 것으로 보여 기본값으로 두지 않는다. 라이브러리 소리 전체의 사용 권리는 이 변경에서 확인하지 않는다.
- 「모든 레이어」 투명도: 화면에 보이는 모든 클립(영상 1, 영상 2 이상의 짤·영상·사진, 자막 클립)과 자막 레이어, 워터마크, 타이틀 바에 투명도를 둔다. 영상 트랙 단위 값은 두지 않는다. 여러 클립을 고르고 한 번에 바꿀 수 있다. 이유: 영상 트랙은 빈 트랙이 사라지면 번호가 바뀌어 트랙 단위 값이 엉뚱한 트랙으로 옮겨 간다.

## 요구사항
1. 해상도는 1080×1920 고정이다. 바꾸는 화면을 두지 않는다.
2. 타임라인 위 「스냅」 switch 왼쪽에 「세이프존」 switch 가 있다. 켜면 미리보기에 세이프존 바깥이 반투명 음영과 선으로 보인다. 경계는 `src/core/geometry.ts` 의 값 그대로다(위 200px, 아래 1480px, 좌우 60px, y 1024px 아래는 오른쪽 버튼 영역 때문에 좌우 160px). 끄면 안 보인다. 내보낸 mp4 에는 들어가지 않는다. 기본은 꺼짐이다.
3. 영상 1·영상 2 이상·자막의 모든 클립과 자막 레이어·워터마크·타이틀 바는 투명도(0~100%, 기본 100%)를 가진다. Inspector 의 슬라이더로 바꾼다. 여러 클립을 고르면 한 번에 바꾼다.
4. 투명도가 지정된 클립을 자르면 두 조각이 같은 투명도를 가진다. 트랙 사이로 옮겨도 투명도가 남는다.
5. 영상 1 만 있고 투명도가 50% 이면 미리보기와 내보낸 mp4 에서 검은 배경 위에 50% 로 보인다.
6. 자막 레이어를 고르면 Inspector 에 자막 편집기가 열린다. 편집기는 폰트(Pretendard·G마켓 산스·티몬체), 메인 크기(기본 56px), 서브 크기(기본 40px), 글자 색, 글자 투명도, 자막바 켜기/끄기, 자막바 색, 자막바 투명도(기본 62%)를 고른다. 레이어 이름(기본 「자막」, 더한 레이어는 「자막 2」…)도 여기서 바꾼다. 바꾸면 미리보기가 바로 바뀐다.
7. 자막 레이어는 메인 줄과 서브 줄을 가진다. 화면에는 메인이 위, 서브가 아래에 보인다. 타임라인은 자막 레이어마다 「메인」「서브」 두 행을 보인다.
8. 「메인·서브 바꾸기」를 누르면 그 레이어의 두 줄 클립이 맞바뀐다.
9. 「자막 레이어 더하기」로 자막 레이어를 더한다. 레이어는 쌓여서 위 레이어가 아래 레이어 위에 그려진다. 레이어마다 위치(가로·세로)를 가진다. 자막바를 끈 레이어가 POV 문구로 쓰인다.
10. 미리보기에서 짤·영상 2 이상 클립·자막 레이어·워터마크를 클릭하면 그 대상이 선택되고 선택 상자가 보인다. 끌면 위치가 바뀐다. 영상 2 이상의 클립(짤·영상·사진)과 워터마크는 모서리를 끌면 폭이 바뀐다(0016). 놓을 때 실행 취소 기록이 1건 남는다. Inspector 슬라이더는 같은 값을 보이고 같이 바뀐다. 방향키는 1% 씩 옮긴다. 「세이프존」이 켜져 있으면 세이프존 경계에 붙는다(「스냅」은 타임라인 시각 스냅만 맡는다). 타이틀 바가 보이는 영상에서는 자막 레이어를 타이틀 바 영역 안으로 옮길 수 없다.
11. 설정 화면의 「브랜드」 카드에서 워터마크 이미지(PNG·JPG·WebP)와 기본 위치·폭·투명도를 정한다. 같은 카드에서 상단 타이틀 바의 기본 높이, 배경 색·투명도, 폰트, 글자 크기·색을 정한다.
12. 모든 영상은 설정의 워터마크·타이틀 바를 공통으로 쓴다. 영상마다 켜기/끄기, 타이틀 글, 타이틀 바 높이·글자 크기·투명도, 워터마크 위치·폭·투명도를 바꿀 수 있다. 영상별 값이 없을 때 워터마크는 설정에 파일이 있으면 보이고, 타이틀 바는 타이틀 글이 있으면 보인다. 글이 빈 타이틀 바는 그리지 않는다. 타이틀 바의 영상별 투명도는 바 전체(배경·글자)에 곱하고, 설정의 배경 투명도는 배경에만 쓴다. 영상에서 바꾼 값은 그 영상에만 남는다.
13. 대본 생성은 장면마다 서브 글(영어)을 함께 받아 서브 줄을 채운다. 받아 적기는 첫 레이어의 메인 행에 자막을 넣고, 그 행에서 시각이 겹치는 클립만 바꾼다. 자막 레이어에서 「서브 자막 만들기」를 누르면 codex 가 그 레이어 메인 행의 글을 번역해 서브 행을 새로 만든다(이전 서브 클립을 바꾸고, 실행 취소로 되돌린다).
14. 대본 → 타임라인 만들기는 설정의 자동 알림음이 켜져 있으면 지정한 시각(기본 3.0초)에 그 소리를 효과음 트랙에 1개 넣는다. 길이는 장면 효과음과 같이 최대 1.5초이고 끝을 0.3초 줄인다(`SCENE_SFX_MAX_SEC`·`SCENE_SFX_FADE_SEC`). 영상이 「시각 + 1.5초」보다 짧으면 넣지 않는다. 넣은 클립은 다른 효과음 클립처럼 옮기고 지운다. 설정 화면의 「자동 알림음」 카드에서 켜기/끄기, 소리(notify 분류, 미리 듣기), 시각(0~10초)을 정한다.
15. 대본 생성은 장면과 함께 제목 1개(최대 30자)를 받아 타이틀 바 글을 채운다. Inspector 의 타이틀 바 편집에 「다시 만들기」(codex 1회)와 직접 고치기가 있다.
16. 이전 project.json(자막 배열 하나, 투명도 없음)은 그대로 열린다. 자막은 첫 레이어의 메인 줄이 되고 스타일은 지금 모양(Pretendard Bold 56px, 흰 글자, 검은 바 62%)이다.

## 설계
- 데이터(`src/core/schema.ts`):
  - `VideoClip`·`OverlayClip`·`TextClip` 에 `opacity?: number`(0~1, 없으면 1)를 더한다. 자르기와 그룹은 객체를 펼쳐 복사하므로 값이 따라간다. 영상 1 ↔ 영상 2 이상 이동(`video-track-edits.ts` 의 `videoClipToOverlay`·`moveOverlayClipToVideo1`)은 필드를 새로 고르므로 `opacity` 를 옮기도록 고친다. 테스트로 고정한다.
  - `Timeline.captionLayers: CaptionLayer[]`. `CaptionLayer { id, name, x, y, opacity?, style: CaptionStyle, main: TextClip[], sub: TextClip[] }`. `x` 는 상자 가운데, `y` 는 상자 아래 끝이다. 기본 위치는 x 0.5, y 1480/1920(세이프존 아래 경계)이다. 서브 행이 보이면 메인 행은 그 위로 올라간다. 이전 자막은 가운데 1450 이었으므로, 옮길 때 첫 레이어는 아래 끝 기준으로 바꾼 값을 쓴다.
  - `CaptionStyle { font: "pretendard" | "gmarket" | "tmon", mainSize, subSize, color, textOpacity, bar: boolean, barColor, barOpacity }`. 굵기는 폰트마다 하나로 고정한다(Pretendard Bold, G마켓 산스 Bold, 티몬체 기본). 측정기와 Remotion 폰트는 이 `font` 값을 키로 찾는다. 타이틀 바 `font` 도 같은 세 값이다.
  - 읽을 때 `captions` 만 있는 Timeline 은 `captionLayers[0].main` 으로 옮긴다. 쓸 때는 `captionLayers` 만 쓴다.
  - `Timeline.brand?: { watermark?: { enabled, x?, y?, width?, opacity? }, titleBar?: { enabled, text, height?, fontSize?, opacity? } }`. 빈 값은 설정 기본값을 쓴다. `timelineToRender` 는 Timeline 과 설정의 브랜드 값을 함께 받는다. 미리보기와 내보내기가 같은 입력을 넘긴다.
  - `settings.json` 의 `brand: { watermark?: { file, x, y, width, opacity }, titleBar: { height, bgColor, bgOpacity, font, fontSize, color } }`. 워터마크 파일은 `<data>/brand/` 에 복사한다.
- 렌더(`src/core/timeline/to-render.ts`, `src/remotion/U3Short.tsx`): 그리는 순서는 영상 1 → 영상 2 이상 → 자막 레이어(아래부터) → 타이틀 바 → 워터마크다. 배경은 지금처럼 검정이다. 실제 투명도는 클립 값 × 레이어 값 × 전환 값이다. 자막은 레이어 스타일로 메인·서브를 각자 맞춘다(지금의 `fitCaptionText` 를 폰트·크기별로 쓴다). 시각이 겹치는 메인·서브는 한 상자 안에 위아래로 놓고, 한쪽만 있으면 그 줄만 놓는다.
- 폰트: G마켓 산스(Bold, OFL)와 티몬체(TMON 라이선스)를 공식 배포처에서 받아 `assets/fonts` 에 라이선스 파일과 함께 넣는다. 파일 형식은 바꾸지 않는다. `src/core/fonts.ts` 의 `FONT_FILES` 와 엔진의 글자 폭 측정기, Remotion 폰트 로딩에 등록한다.
- 화면:
  - 타임라인 머리(`Timeline.tsx`)에 `StudioSwitch` 「세이프존」을 「스냅」 왼쪽에 둔다.
  - 편집 층은 Remotion 과 무관한 컴포넌트(`src/ui/studio/PreviewEditLayer.tsx`)로 만든다. 입력은 대상 목록(id, 정규화 상자, 크기 조절 여부)이고 출력은 정규화 좌표 변경이다. 033 의 캐러셀 미리보기가 같은 컴포넌트를 쓴다. 미리보기(`Preview.tsx`)에 Player 와 같은 크기로 이 층을 겹친다. 렌더 요소에 `data-u3-target` 을 붙이고, 편집 층이 그 요소의 화면 상자로 선택 상자를 그린다. 포인터 거리를 미리보기 폭·높이로 나눠 정규화 좌표로 바꾼다. 재생 중에 끌기를 시작하면 재생을 멈춘다. 전환 효과가 걸린 프레임에서는 저장 좌표로 상자를 그린다.
  - 타임라인(`timeline-adapter.ts`)은 자막 레이어마다 두 행(메인·서브)을 만든다. 자르기·옮기기·지우기는 행 안에서 지금 자막과 같다.
  - Inspector 의 자막 편집기는 SEED Select·Slider·Switch 를 쓴다. 색 고르기는 SEED 에 해당 컴포넌트가 있는지 공식 문서로 확인하고, 없으면 MIT 라이선스의 작은 색 선택 라이브러리를 쓴다. 고르는 일은 plan 에서 한다.
  - 설정 화면에 「브랜드」 카드를 더한다. 워터마크 파일은 Tauri 파일 선택 창으로 사용자가 고른다.
- codex 실행기: `src/engine/pipeline/codex.ts` 의 실행기를 출력 스키마와 지시문을 인자로 받게 일반화한다. 030 과 같은 일반화이므로 plan 의 첫 공통 단위 하나로 만들고 두 변경이 함께 쓴다. 번역·제목 다시 만들기는 대본 설정의 모델·effort 를 쓰고 프레임을 넣지 않는다. 번역 입력은 메인 행 글 목록, 제목 입력은 대본 장면 글이다. 설정의 대본 프롬프트(031)는 넣지 않는다.
- API: `GET/PUT /api/system/brand`, `POST /api/system/brand/watermark`(파일 복사), `POST /api/projects/:id/captions/translate { layerId }`(codex 번역, 결과는 서브 클립 목록). `POST /api/projects/:id/title`(codex 로 제목 다시 만들기), `GET/PUT /api/system/intro-sfx`. 대본 스키마의 장면에 `subCaption`, 대본에 `title` 을 더하고 031 의 형식 규칙에 두 항목을 적는다.
- 자동 알림음: `settings.json` 의 `introSfx: { enabled, ref, atSec }`. `timelineFromScript`(`src/core/timeline/from-script.ts`)가 장면 효과음을 넣은 뒤 이 클립을 새 효과음 트랙(lane)에 넣는다. 장면 효과음과 겹쳐도 옮기지 않는다.
- 미디어: 미디어 서버에 `brand` 루트를 더해 미리보기와 렌더가 워터마크를 URL 로 읽는다.

## 결정
- 편집 모델을 고친다: 자막 레이어 여러 개(메인·서브 두 줄, 레이어 스타일·위치), 모든 화면 클립의 투명도, 브랜드 요소(워터마크·타이틀 바)를 설정 기본값과 영상별 값으로 둔다. 자막 폰트 세 가지를 앱에 넣는다. 0012 를 대체한다 → [0016](../../decisions/0016-caption-layers-opacity-brand.md)

## 우려 사항
- 티몬체 라이선스 문구가 엇갈린다. 2차 출처는 「자유롭게 수정·재배포」와 「수정·다른 형식 변환 금지」를 함께 옮긴다. 소프트웨어 임베딩은 허용된다고 적는다. 공식 배포처는 2024년 이후 열려 있는지 확인하지 못했다. 정책 소유자: 개발자(sumin.p). 추천: 받은 원본 파일과 라이선스를 형식 변환 없이 그대로 넣고, 공식 배포처에서 받지 못하면 티몬체를 빼고 알린다. 이유: 라이선스 원문을 확인할 수 없는 파일을 배포하지 않는다.
- 0012 를 대체한다(0016). 범위 결정은 이 브랜치에서 0003 이고, intent 의 「0014(TTS 없음)」는 0003 의 같은 내용을 뜻한다. 030·033 이 병합되면 0017 이 범위를 맡는다. 자막이 「트랙 하나」에서 「레이어 여러 개 × 두 줄」로 바뀌어 타임라인 행 수가 늘어난다. 정책 소유자: 사용자. 추천: 이대로 간다. 이유: 사용자가 두 줄 자막과 자막 레이어를 요구했다.
- 서브 자막의 번역은 codex 호출이 늘어난다(대본 생성 때 한 번, 「서브 자막 만들기」 때마다 한 번). 정책 소유자: 사용자. 추천: 대본 생성에 함께 받아 추가 호출을 줄인다. 이유: 구독 한도를 쓴다.
- 미리보기 끌기는 DOM 동작이라 vitest 로 시험할 수 없다(jsdom 없음). 정책 소유자: 사용자(직접 검증하기로 함). 처리: 좌표 변환·스냅·기록 1건은 순수 함수로 시험한다. 끌기 단위가 병합되면 조정자가 사용자에게 검증 요청(확인할 동작 목록과 빌드 위치)을 낸다.
- 작업량이 크다. 030 과 codex 실행기·미디어 서버 루트·`settings.json`·설정 카드·`/api/system/*` 를 함께 바꾼다. 정책 소유자: 개발자. 추천: codex 실행기 일반화를 공통 단위로 먼저 병합하고, 032 를 030 보다 먼저 병합한다. 030 은 032 위에 rebase 한다. 033 은 둘 다 병합된 뒤 구현한다. 이유: 같은 함수를 두 번 일반화하지 않고, 겹치는 파일의 충돌을 한쪽에서만 푼다.
- 라이브러리 notify 분류의 소리(「카톡」「iPhone Notification」, TV 프로그램 효과음 포함)는 모두 고를 수 있다. 출처는 myinstants 이고 사용 권리를 확인하지 않았다. 정책 소유자: 사용자. 추천: 이 변경에서는 기본값만 「띠링- 소리」로 두고 목록은 그대로 둔다. 라이브러리 권리 점검은 따로 한다. 이유: 라이브러리 전체의 문제이고 이 변경 범위보다 크다.

## 검증 기준
- `pnpm verify` 가 종료 코드 0 이고 마지막 줄이 `✓ verify passed` 다.
- 테스트(vitest):
  - 이전 project.json 읽기 → 첫 레이어 메인 줄로 옮김
  - 투명도가 자르기·트랙 이동 뒤에도 남음
  - 렌더 변환의 투명도 곱
  - 그리는 순서
  - 메인·서브 바꾸기
  - 서브 클립 시각이 메인과 같게 만들어짐
  - 미리보기 좌표 ↔ 정규화 좌표 변환과 세이프존 스냅
  - 끌기 한 번이 실행 취소 기록 1건
  - 브랜드 설정 저장·검증과 영상별 값 병합
  - 폰트·크기별 자막 맞추기
  - 대본 스키마의 `subCaption`·`title`
  - 자동 알림음: 켜짐이면 지정 시각에 1개(최대 1.5초), 꺼짐이면 없음, 영상이 「시각 + 1.5초」보다 짧으면 없음
  - 영상 1 ↔ 영상 2 이상 이동 뒤 투명도 유지
  - 이전 자막 위치(가운데 1450) → 아래 끝 기준 변환
  - 받아 적기가 첫 레이어 메인 행의 겹치는 클립만 바꿈
  - 브랜드 기본 보임 규칙(파일 없음·빈 타이틀 글)
  - 타이틀 바 영역으로 자막 레이어 이동 제한
- 실제 확인(개발자 1회, 앱 창 캡처):
  - 세이프존 켜고 끄기
  - 영상 1 투명도 50%
  - 자막 편집기로 폰트 세 가지
  - 두 줄 자막과 바꾸기
  - POV 레이어 끌어 옮기기(사용자 검증)
  - 짤 끌어 옮기기(사용자 검증)
  - 워터마크·타이틀 바가 내보낸 mp4 에 보임
